# assets/

**Ready (12 September 2026).** Real PNGs are in this folder. `src/sprites.js`
auto-loads the 12 sprite files at startup (alpha-trimmed, contain-fit,
color-normalized) and keeps procedural art only if a file is missing.

Wired sprites: `coffee-man.png`, `tea-girl.png`, `uncle-pete.png`,
`tuado.png`, `minion.png`, `bat.png`, `pipe.png`, `staff-yellow.png`,
`crate-stash.png`, `gym-bench.png`, `lava-blob.png`, `lava-splash.png`.

Present but not wired: `logo.png` (start screen), `wall-metal.png` (raycast
walls), `icon-180.png` (Apple touch icon).
