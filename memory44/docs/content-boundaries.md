# Original-content boundaries

This project may use general ideas common to tactics games: hexagonal spaces,
turns, terrain, movement ranges, attacks, objectives, and historical subject
matter. Its particular expression must remain original.

Do not import, trace, transcribe, scrape, or closely recreate any third-party:

- game title, logo, trade dress, or publisher branding;
- rulebook wording, card text, flavour text, or unit-summary text;
- board art, icons, miniatures, sound, animation, or interface layout;
- published or community scenario map, setup, objectives, or briefing; or
- source code, extracted game data, network protocol, or hidden assets.

Every map should begin from a new design goal and a blank grid. Keep design
notes explaining that goal. Use public-domain historical sources for factual
research and write all resulting copy independently.

If the project later needs compatibility, brand references, or licensed
material, pause implementation until the rights holder gives written permission
and a qualified lawyer reviews the intended use in each release market.
