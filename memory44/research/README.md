# memory44 research

Research notes for the memory44 project: a functional study of a classic WWII
hex-grid, card-driven wargame system, compiled from public online sources on
06 September 2026. Everything here is summarized in original prose. No artwork,
scans, card text, rules prose, or setup maps were copied or downloaded; the
source game, its designer, and its publisher are deliberately not named.

## Files

- `mechanics.md` — core rules: turn structure, sections, ordering, movement,
  combat sequence, line of sight, terrain effects, retreats, medals, victory.
- `command-cards.md` — the 60-card command deck: 40 section cards and 20 tactic
  cards, exact counts per type, and a functional description of each.
- `dice-and-combat.md` — the 8 battle dice, six faces, per-die hit chances,
  dice-per-range tables, and computed combat probabilities.
- `components-inventory.md` — full physical inventory of the base box: 144
  miniatures, 44 terrain tiles, obstacles, medals, badges, reference cards.
- `expansions.md` — every official expansion in release order, with what each
  adds functionally.
- `visual-style.md` — functional description of board, miniature, card, dice,
  and tile art direction, with guidance for creating a distinct original style.
- `board-and-terrain.md` — board geometry (13 × 9 hexes, 4/5/4 sections),
  coordinate convention, both board faces, and the full terrain/obstacle
  effect catalog.
- `base-scenarios.md` — all 16 standard scenarios plus the bonus two-board
  scenario: dates, sides, force mixes, card hands, medal targets, tactical
  character. No setup maps reproduced.
- `scenario-design-patterns.md` — how scenarios are constructed and balanced,
  common special-rule patterns, and a checklist for designing original ones.

## Intended use

These notes describe mechanics, counts, and facts so the project can build an
original game on comparable systems. Per the project rules in `AGENTS.md`,
every shipped expression — names, art, card text, scenarios — must be
independently authored. Do not copy expressive content from the source game.
